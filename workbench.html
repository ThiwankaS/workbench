Install

git clone https://github.com/ThiwankaS/workbench.git ~/.config/nvim
cd ~/.config/nvim
bash ./scripts/bootstrap.sh
nvim

First launch

:lua vim.pack.update()
:checkhealth vim.pack
:MasonInstallAll
:TSInstall c cpp javascript python markdown markdown_inline

Set terminal font to JetBrainsMono Nerd Font (bash ./scripts/install_jetbrains_mono_nerd.sh).

Explore a Codebase

Open a project

cd /path/to/your/repo
nvim .

C/C++ — compile database

cmake -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build build
ln -sf build/compile_commands.json .
:LspRestart

Obsidian notes (optional)

Edit lua/config.lua → obsidian_vault, or export an env var:

export OBSIDIAN_VAULT="$HOME/path/to/vault"

Markdown + Mermaid preview

Store docs as .md or standalone .puml files. Mermaid uses fenced blocks:

```mermaid
graph LR
  A --> B
```

PlantUML — use a .puml file or a fenced block in markdown. Must close with @enduml (not @startuml again):

```plantuml
@startuml
title Example
start
:Step;
stop
@enduml
```

PlantUML diagrams render via plantuml.com — you need internet. Then Spacemp in the buffer.

Workflow

  1. Spacef open a file · Spaceu outline
  2. On a function: Spacesi callers · Spaceso callees
  3. gd / gr jump · list usages
  4. Spacesw find symbol project-wide
  5. Spacesn architecture note (needs vault)
  6. Spacemp preview markdown + Mermaid in browser
  7. In markdown notes: gf on [[links]]

Browser Preview

Live preview in your default browser via markdown-preview.nvim. Works on .md and standalone .puml files.

How to use

  1. Open a markdown or PlantUML buffer.
  2. First time only: :MarkdownPreviewInstall
  3. Press Spacemp to toggle preview.

Mermaid (in .md)

```mermaid
graph LR
  A --> B
```

PlantUML

Use a .puml file or a fenced block. Close with @enduml — not a second @startuml:

```plantuml
@startuml
title Example
start
:Step;
stop
@enduml
```

PlantUML renders through plantuml.com — internet required. Mermaid renders locally in the preview server.

Prefer Spacemp over :MarkdownPreviewToggle; the keymap checks filetype and loads the plugin safely.

Configuration

User-editable settings live in one place. Plugin wiring lives in lua/setup/. Restart Neovim after edits.

User settings — lua/config.lua

obsidian_vault = "~/Documents/Obsidian/Main"  -- Space sn notes; nil to disable
preview_filetypes = { "markdown", "plantuml" } -- Space mp filetypes
lsp_servers = { "clangd", "typescript-language-server", "pyright" }

Load order — init.lua

  1. Leader + paths (config.lua → vim.g.obsidian_vault)
  2. Editor options + diagnostics (core/options.lua)
  3. Preview globals (setup/markdown_preview.configure())
  4. Plugins (vim.pack.add)
  5. Plugin setup modules (setup/*.setup())
  6. Global keymaps last (core/keymaps.lua)

Shared lists — lua/core/filetypes.lua

Single source of truth for which buffers skip global leader maps (ui_plugin) and LSP maps (lsp_skip).

Theme — lua/chadrc.lua

Default theme gruvbox. Spacett toggles gruvbox ↔ onedark. Statusline includes a live clock (setup/clock.lua).

Troubleshooting

Plugins

:checkhealth vim.pack
:lua vim.pack.update()

clangd quit / no diagnostics

:LspInfo
:LspRestart

Add compile_commands.json at project root (see Explore section).

Call hierarchy empty

Cursor on a symbol · LSP attached · C++ needs compile database.

Live grep empty

sudo apt install ripgrep

Alt+j/k not working

Terminal must send Meta/Alt keys. In Ghostty: enable option-as-meta.

Theme toggle does nothing

Edit theme_toggle in lua/chadrc.lua — both names must be valid Base46 themes (e.g. gruvbox, onedark, not oned_dark).

Markdown preview (Space mp) not working

  1. Open a .md or .puml file first.
  2. Run once: :MarkdownPreviewInstall
  3. Then Spacemp — browser should open via xdg-open.
